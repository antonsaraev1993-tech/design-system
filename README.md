# design-knowledge: Главподряд

Учебный разбор идеи «дизайн-система как знание, которым ты владеешь» на примере публичного сайта glavpodryad.pro. Это не заказ: компания в работе не участвовала, наблюдения взяты с её главной страницы.

Три слоя, связанные между собой:

```
problems/      что не так, у кого и как это видно        (язык описания проблем)
   │  tags ↔ solves
patterns/      как эта система предпочитает такое решать  (+ composition/)
   │  uses
components/    из чего собирается решение                 (на tokens/, DTCG)
```

Сверху лежит `invariants/`: сущность компании, которую редизайн не трогает. Снизу `decisions/`: след каждого решения, чтобы было видно, почему сделано именно так.

Всё это просто файлы под git. Не привязано ни к Figma, ни к конкретному AI-продукту: любой агент читает `AGENTS.md` и работает по тем же правилам.

## Проверка

```
pip install pyyaml
python3 scripts/check.py
```

Скрипт проверяет связность графа: у каждой проблемы есть паттерн, паттерны ссылаются на существующие компоненты, компоненты используют существующие токены, решения ссылаются на реальные проблемы и паттерны, теги взяты из словаря.
