# Прототип главной

Главная, собранная по решениям `decisions/D-001…D-003`. Цель — показать изменённые блоки, а не готовый сайт: блоки без решений стоят заглушками, неизвестные факты видны как метки `[уточнить]`.

## Как посмотреть

Открыть `prototype/index.html` в браузере (двойной клик по файлу). Кнопка «Скрыть пометки» убирает подписи о том, какое решение отвечает за блок.

## Откуда значения

- Цвета, размеры шрифтов, отступы, радиус: только из `tokens.css`. Он генерируется из `tokens/tokens.json`:
  ```
  python3 scripts/tokens_css.py
  ```
  После изменения токенов перезапустить скрипт, прототип подхватит новые значения.
- Сетка 12/4 колонки, 3 карточки в ряд, текст не шире 8 колонок: `composition/grid.md`.
- Тексты и цифры: `invariants/brand.yaml` и решения. Ничего сверх них не добавлено.

## Чего не хватает в токенах

Прототип упёрся в пробелы дизайн-системы. Их стоит закрыть токенами, а не значениями в коде:

- нет семейства шрифтов: временно `system-ui`;
- нет размера для заголовка первого экрана: используется `font.size.h2`;
- нет межстрочного интервала и насыщенности шрифта;
- нет точки перелома desktop/mobile: временно 760px;
- нет толщины обводки фокуса: временно 2px;
- нет тёмной темы.

Эти места помечены комментариями в `index.html`.
