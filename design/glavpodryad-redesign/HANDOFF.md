# Главподряд: пакет редизайна главной

Редизайн главной glavpodryad.pro. Принцип: **редизайн без смены сущностей**. Контент, количество элементов, тон и фирменные цвета совпадают с текущим сайтом, меняется только подача.

## Что в пакете

| Папка | Что | Как использовать |
| --- | --- | --- |
| `design-system/tokens.css` | CSS-переменные (`--color-accent`, `--space-section`…) и базовые стили ссылок | Источник правды для стилей. Подключить первым. |
| `design-system/tokens.json` | Те же токены с описанием назначения | Справка: где какой токен применяется. |
| `design-system/README.md` | Брендбук: голос, цвет, ритм секций, типографика, доступность, состав главной | Правила, которые нельзя нарушать при вёрстке. |
| `components/*.dc.html` | 15 компонентов и страница `Main.dc.html` в формате Design Component | Эталон разметки и стилей (см. ниже, как читать). |
| `components/*.md` | Правила и свойства каждого компонента | Варианты, состояния, ограничения. |
| `tokens/` | Те же токены для Figma: Tokens Studio, W3C, вариант для DS Generator | В вёрстку не нужны. |

## Как читать `.dc.html`

Это шаблоны редактора макетов, а не готовые страницы. Внутри `<x-dc>` обычная разметка с inline-стилями на `var(--…)`, плюс:

- `{{имя}}` — подстановка значения из `renderVals()` в `<script type="text/x-dc">` внизу файла;
- `<sc-for list="{{items}}" as="item">` — цикл; `<sc-if value="{{cond}}">` — условие;
- `<dc-import name="Button" label="…" variant="outline">` — вставка компонента `Button.dc.html`, атрибуты (kebab-case) = его свойства (camelCase);
- `<script src="./support.js">` и `<link href="/_blob/…">` — служебные строки редактора: support.js не нужен, `/_blob/…` = `design-system/tokens.css`;
- `<helmet>` — то, что идёт в `<head>`: шрифты Google Fonts (Unbounded 400/500/600, Manrope 400/500/600/700).
